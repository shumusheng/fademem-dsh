# 会遗忘的角色

装上之后，DSH 里对话的对象会开始记住你说过的事，也会慢慢忘掉；说话方式从"助手"变成"人"。

不需要另开代理、不用改 Base URL、不用装第二个客户端。

## 它做了什么

每收到一条你的消息，插件做两件事：

1. **记**：从这句话里抽稳定事实（叫什么、住哪、养了什么、喜欢和讨厌什么、生日、承诺）。只抽稳定的，情绪和临时状态不记。
2. **注入**：下一次组装提示词时，把「角色设定 + 现在还够清晰的记忆 + 说话规则」拼进系统提示。

关键在于记忆**不是一直清晰**。每条记忆有自己的稳定性，按 `R = exp(-时间/稳定性)` 衰减：

- 一周没提到，中等重要的记忆已经模糊
- 更久没提到，只剩一个印象——此时**文字本身会被磨花**：数字变成"几个"、括号里的补充消失、长句在分句处断成"……"
- 被再次提到，稳定性按间隔效应拉长（越模糊时想起，记得越牢）

所以它忘得是真的，不是假装忘。

## 配置

插件配置是 JSON，在你安装插件时由 DSH 的插件配置项传入。全部可选，一个不写也能用：

```json
{
  "persona": {
    "name": "沈知夏",
    "description": "二十七岁，在一家做城市改造的小事务所画图。",
    "personality": "嘴上不饶人，心软。讨厌被可怜。",
    "relationship": "认识三个月的邻居，见过几次面，还没到交心的地步。",
    "scenario": "晚上十一点，楼道里的灯坏了一盏。",
    "speech": { "address": "你", "verbalTics": ["……行吧", "随你", "嗯"] },
    "boundaries": ["不主动说自己的过去"]
  },
  "memoryFile": "~/.fademem/dsh-memory.json",
  "baseStabilityDays": 6.0,
  "maxItems": 8,
  "ambientItems": 2,
  "style": true
}
```

| 字段 | 作用 |
|---|---|
| `persona` | 角色卡。`relationship` 最影响观感，它决定亲疏 |
| `memoryFile` | 记忆存在哪。换角色就换这个文件 |
| `baseStabilityDays` | **记性松紧**。默认 6（比人还健忘）；12 明显变好；2 就是金鱼 |
| `maxItems` | 每轮最多注入几条记忆，默认 8 |
| `ambientItems` | 无关话题也补几条"一直知道"的事，默认 2 |
| `style` | 是否注入说话规则，默认开 |

## 记忆放在哪

默认 `~/.fademem/dsh-memory.json`。一个纯 JSON 文件，按会话分桶，你可以直接打开看它记住了什么——这也是调试角色最好的方式。

删掉它等于让角色失忆。

## 局限

- 抽取靠正则，认不出"我一闻到香菜就想吐"这种绕弯表达。宁可漏记，不乱记。
- 只记用户说的话，不从小助理的回答里抽事实。
- 说话规则靠提示词约束，管不住所有模型；模型越"听话"，人味越明显。
- 记忆库是文件读写，会话特别长时偶尔会慢一点。

## 兼容

需要 DSH 0.2.x。插件只依赖 `ctx.systemPrompt` 与 `session/event` 两个接口，两者都缺失时会安静地不工作，不会中断对话。
